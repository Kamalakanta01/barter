# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting for this repository
(**Security** → **Report a vulnerability**). Include the affected version, the platform, and the
steps to reproduce. You can expect an acknowledgement within a few days.

If private reporting is unavailable, open a public issue containing only a one-line notice asking for
a private contact method, with no technical detail.

## Supported versions

Security fixes land on the latest release only.
